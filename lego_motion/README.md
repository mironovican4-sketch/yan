# LEGO-персонаж · «рука к лицу» · 5 секунд, луп

Персонаж целиком векторный: каждая деталь — шейп-слой After Effects с ровными заливками и одинаковой обводкой 9 px. Края чёткие при любом масштабе, кривых срезов нет. Он стоит и дышит, берёт замах, поднимает руку вперёд-вверх, как настоящая минифигурка, и закрывает ладонью лицо, чуть опуская голову, — как на референсе. Затем держит позу и возвращается в стартовое положение ровно к 5-й секунде, поэтому ролик крутится без шва.

![Раскадровка](preview/storyboard.jpg)

Превью: [`preview/lego_facepalm_preview.mp4`](preview/lego_facepalm_preview.mp4) (1080×1350, 30 fps, 5 с).

## Как собрать в After Effects

1. Откройте After Effects (CC 2018 или новее).
2. `File → Scripts → Run Script File…` → `build_lego_motion.jsx`. Файл `lego_vectors.jsxinc` должен лежать рядом со скриптом: в нём контуры всех деталей.
3. Откроется композиция `LEGO_FACEPALM`.

## Тайминг

| Время | Движение |
|---|---|
| 0.00–0.55 | стоит и дышит |
| 0.55–0.85 | замах: рука чуть уходит наружу, корпус наклоняется |
| 0.85–2.20 | рука поднимается вперёд-вверх (вращение в плече, как у минифигурки), кисть ложится на глаз с перелётом и досадкой, голова опускается |
| 2.20–4.15 | держит позу, дышит |
| 4.15–5.00 | рука возвращается вниз в стартовую позу, дальше луп |

## Слои

Каждая деталь — отдельный шейп-слой. Внутри:
- группы цветных кусков (у каждого заливка и обводка);
- группа `Line Art` — лицо, борода, пресс, роза, швы.

Контуры лежат в координатах исходной картинки 1122×1500, поэтому у ребёнка Position равна точке сустава.

| Слой | Родитель | Что внутри |
|---|---|---|
| `LEGS` | — | бёдра и штанины; здесь масштаб и место в кадре |
| `TORSO` | LEGS | торс, пресс, роза; дыхание — выражение на Scale |
| `HEAD` | TORSO | кепка, верх кепки, лицо, шея (шея уходит под торс, щели при наклоне нет) |
| `ARM_L` | TORSO | цельная рука с манжетой в группе `Arm`. Подъём вперёд — Scale этой группы (100 → −75 %) + Rotation 24° у слоя. Обводка снаружи группы, поэтому толщина линии не меняется |
| `HAND_L` | TORSO | запястье + C-ладонь. Едет за концом руки выражением, масштаб руки не наследует; при подъёме увеличивается до 112 % (ближе к камере) |
| `ARM_R` → `HAND_R` | TORSO | вторая рука, лёгкое покачивание |
| `CONTROLS` | — | цвета `Skin`, `Hat`, `Pants`, `Outline`, `Background`; `Breath`, `Shadow Opacity` |
| `FLOOR_SHADOW`, `BG` | — | тень под ногами и фон |

Анимация — обычные ключи Rotation и Scale (у головы ещё Position) с плавным easing, на слое `CONTROLS` стоят маркеры фаз.

## Частые правки

- **Цвета** кожи, кепки, штанов, обводки и фона — слой `CONTROLS`.
- **Закончить на позе «рука на лице», без возврата:** удалите ключи после 4.15 с у `ARM_L`, `HAND_L`, `HEAD`, `TORSO` или обрежьте рабочую область на 4.1 с.
- **Положение кисти на лице:** `ARM_L` — Scale группы `Arm` −75 %, Rotation 24°; `HAND_L` — Rotation −114°, Scale 112 %.
- **Размер и место в кадре:** `charScale` и `feet` в `CFG` скрипта или Scale/Position у `LEGS`.

## Инструменты

```bash
pip install numpy opencv-python-headless pillow imageio-ffmpeg potracer
python3 tools/vectorize.py character.webp lego_vectors.jsxinc   # картинка -> векторные контуры деталей
python3 tools/render_preview.py --out preview.mp4 --sheet storyboard.jpg
npm i acorn && node ../nike_loop/tools/ae_mock_check.js build_lego_motion.jsx
```

`vectorize.py` трассирует каждый цветной кусок до середины его чёрного контура (потом его рисует обводка) и линии внутри деталей. Всё сглаживается кривыми Безье. `render_preview.py` строит превью из тех же контуров, рига и ключей.

> Скрипт проверен на имитации API After Effects: настоящего AE в среде сборки нет. При первом запуске загляните в итоговое окно — если что-то пойдёт не так, там будет текст ошибки.
