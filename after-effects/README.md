# Reel Recreate: скрипт для After Effects

`reel_recreate.jsx` собирает вертикальный рилс 1080×1920 в стиле эдитов [naughtyyjuan](https://www.instagram.com/naughtyyjuan/). Нужны только встроенные эффекты AE, плагины не требуются.

> ⚠️ Референс ([рилс DMgIGCbS0Vj](https://www.instagram.com/naughtyyjuan/reel/DMgIGCbS0Vj/)) из моей среды не открылся, Instagram там заблокирован. Скрипт повторяет типичный моушн naughtyyjuan: панчи и тряску в бит, velocity, RGB-сплит, Turbulent Displace, вспышки, glow и 3D-текст. Чтобы подогнать его точно под этот рилс, пришли 5–8 скриншотов по ходу видео или сам файл .mp4 и опиши, что происходит по секундам.

## Как запустить

1. Открой проект в After Effects.
2. В панели **Project** выдели своё видео. Если есть отдельный трек (.mp3/.wav), выдели и его через Ctrl/Cmd.
   Если ничего не выделить, скрипт поставит анимированную заглушку, и моушн всё равно будет видно.
3. **File → Scripts → Run Script File…** (в русской версии: **Файл → Сценарии → Запустить файл сценария…**) и выбери `reel_recreate.jsx`.
4. Комп `REEL_RECREATE` откроется сам. Нажми **пробел** для превью.

Весь скрипт отменяется одним **Ctrl/Cmd+Z**.

## Что внутри компа

| Слой | Что делает |
|---|---|
| **BEAT CONTROL** | Маркеры-удары и слайдеры силы эффектов. Отсюда управляется всё остальное |
| FLASH | Белая вспышка на DROP |
| FX GRADE | Контраст, Vibrance, Glow (пульсирует на DROP), зерно |
| VIGNETTE | Виньетка |
| FX DISTORT | Turbulent Displace: рвёт картинку на DROP |
| TITLE / SUBTITLE | 3D-текст влетает на второй DROP, трекинг расходится, мерцание на ударах |
| CAM | Zoom-панч и тряска на каждый удар |
| SRC R / G / B | Три копии видео по каналам. На ударе они разъезжаются, получается RGB-сплит. На них же velocity |

## Как подогнать под свой трек

- **Удары:** маркеры на слое `BEAT CONTROL`. Их можно двигать, удалять и добавлять (клавиша `*` на цифровой клавиатуре). Эффекты сами перестраиваются.
- **DROP:** двойной клик по маркеру и в поле Comment напиши `DROP`. На таком маркере сильный зум, вспышка, дисторшн и мерцание текста.
- **Сила эффектов:** слайдеры `Punch`, `Shake`, `RGB Split`, `Distort`, `Flash`, `Velocity` на `BEAT CONTROL`. Ноль выключает эффект.
- **Перед запуском** в начале файла, в блоке `CFG`, можно поменять BPM трека, секунду первого удара, текст, шрифт и цвет. Если поставить `renderNow: true`, скрипт сразу отрендерит .mp4 на рабочий стол.
