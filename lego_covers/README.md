# LEGO COVERS · персонажи показывают обложку · 1000×1000 · 3 с, луп

Те же векторные LEGO-персонажи с ровной обводкой, что и в `lego_squad` / `lego_scenes`, только теперь каждый держит обложку и показывает её в камеру. Композиция 1000×1000, 30 fps, 3 секунды, луп без шва.

| Композиция | Что происходит | Превью |
|---|---|---|
| `LEGO_SMILE_VARSITY_COVER` | Спокойно держит обложку в вытянутой руке на уровне груди, пару раз слегка её потряхивает, смотрит в камеру и дышит. Без трюков, наряд всё время виден | [mp4](preview/smile_varsity_cover.mp4) · [раскадровка](preview/smile_varsity_cover_storyboard.jpg) |

## Как собрать в After Effects

1. Нужен After Effects 2020 или новее.
2. Рядом со скриптом должны лежать папки `scenes/` (данные сцены) и `assets/` (обложка `cover_for_all_the_dogs.png`).
3. `File → Scripts → Run Script File…` → `build_lego_covers.jsx`. В проекте появится папка `LEGO_COVERS` с композицией и картинкой обложки.

## Слои

- Персонаж: `LEGS` → `TORSO` → `HEAD` / `ARM_L` → `HAND_L` / `ARM_R` → `HAND_R`. Руки — оригинальные детали, правая только поворачивается в плече.
- `COVER` — картинка обложки (футаж), ребёнок `HAND_R`. Кисть держит её за нижний край у левого угла. Rotation посчитан покадрово, чтобы обложка стояла ровно и чуть наклонялась при каждом потряхивании.
- `COVER_FRAME` — тонкая обводка вокруг обложки в стиле персонажа.
- Чтобы поставить другую обложку, замените файл в `assets/` на квадратный PNG с тем же именем, или впишите другое имя в `COVER` в `tools/covers.py` и пересоберите сцену.

## Инструменты

```bash
python3 tools/covers.py                                            # сцены -> scenes/*.jsxinc и build_lego_covers.jsx
python3 ../lego_scenes/tools/render.py all --root .                # превью mp4 + раскадровки -> preview/
npm i acorn && node ../nike_loop/tools/ae_mock_check.js build_lego_covers.jsx
```

Сцены описаны на том же наборе, что и `lego_scenes` (`scenekit.py`, `scenes.py`). Скрипт для AE и превью читают одни и те же данные, поэтому превью совпадает с композицией.

Векторы персонажа в `vectors/` пересобраны из исходника (`../lego_squad/tools/vectorize_squad.py`, `ONLY=SMILE_VARSITY`): для этого персонажа выключено правило «золотой цепочки» и заливаются мелкие дырки зерна. Поэтому кожа лица сплошная, без тёмных «волосков», а жёлтая бусина в волосах снова жёлтая.

> Скрипт проверен на имитации API After Effects (1 композиция, 12 слоёв, ошибок нет): настоящего AE в среде сборки нет. Если при запуске что-то пойдёт не так, текст ошибки будет в итоговом окне.
